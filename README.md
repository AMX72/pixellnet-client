# PIXELLNET

Стабильная связь одной кнопкой. Скоро — ИИ-помощник и расширения.

## Скачать

https://download.pixellnet.com — приложения для Windows и Android.

## Поддержка

https://t.me/pixellnet_support

## О коде

В этом репозитории — исходный код приложения PIXELLNET. Выпуски собираются автоматически через GitHub Actions.

## Авторство и лицензия

Основано на открытом проекте Hiddify (https://github.com/hiddify/hiddify-app). Лицензия — см. [LICENSE.md](LICENSE.md); оригинал лицензии: https://github.com/hiddify/hiddify-app/blob/main/LICENSE.md.

Что изменено относительно Hiddify: название, значки, тексты и оформление; упрощён главный экран; приложение подключено к сервису PIXELLNET (получение ключа, пробный период, обновления); добавлены правки для Windows и Android.
